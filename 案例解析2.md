# 案例解析2：`for` 循环脱糖 + 斐波那契

---

## 源码

```lox
var a = 0;
var temp;
for (var b = 1; a < 3; b = temp + b) {
  print a;
  temp = a;
  a = b;
}
```

**预期输出：**
```
0
1
1
2
```

## 第二阶段：Parser 语法解析 + for 脱糖

**输入：** Token 列表
**输出：** AST（`for` 已脱糖为 `Block + While`）

### for 语句脱糖过程

`forStatement()` 解析出三个子句和循环体后，按以下步骤组装：

```
原始 for 三个子句：
  初始化式：  Stmt.Var("b", Literal(1.0))
  条件式：    Expr.Binary(Variable("a"), <, Literal(3.0))
  增量式：    Expr.Assign("b", Binary(Variable("temp"), +, Variable("b")))

原始循环体（花括号块）：
  Stmt.Block([
    Stmt.Print(Variable("a")),
    Stmt.Expression(Assign("temp", Variable("a"))),
    Stmt.Expression(Assign("a",    Variable("b")))
  ])

─── 脱糖步骤 1：把增量式追加到循环体末尾 ───────────────────
body = Stmt.Block([
    原始循环体,
    Stmt.Expression(Assign("b", Binary(Variable("temp"), +, Variable("b"))))
])

─── 脱糖步骤 2：用条件式包裹为 While ────────────────────────
body = Stmt.While(
    condition: Binary(Variable("a"), <, Literal(3.0)),
    body:      上一步的 Block
)

─── 脱糖步骤 3：把初始化式前置到 Block 中 ───────────────────
body = Stmt.Block([
    Stmt.Var("b", Literal(1.0)),
    上一步的 While
])
```

### Step 5~8：While 循环迭代

每次迭代：先检查条件 → 执行原始循环体 → 执行增量式

---

#### 迭代 1

**检查条件：** `a < 3` → `0.0 < 3.0` → **true**

```
执行原始循环体：
  Stmt.Print(Variable("a"))
      └── environment.get("a") → for-env 无 → global 返回 0.0
      └── stringify(0.0) → "0"
      └── 输出：0

  Assign("temp", Variable("a"))
      └── evaluate(Variable("a")) → 0.0
      └── environment.assign("temp") → global.temp = 0.0

  Assign("a", Variable("b"))
      └── evaluate(Variable("b")) → for-env 返回 1.0
      └── environment.assign("a") → global.a = 1.0

执行增量式：
  Assign("b", Binary(Variable("temp"), +, Variable("b")))
      └── evaluate(Variable("temp")) → global.temp = 0.0
      └── evaluate(Variable("b"))   → for-env.b = 1.0
      └── 0.0 + 1.0 = 1.0
      └── environment.assign("b")   → for-env.b = 1.0
```

```
迭代1 结束：
  for-env: { b→1.0 }
  global:  { a→1.0, temp→0.0 }
  已输出：  0
```

---

#### 迭代 2

**检查条件：** `a < 3` → `1.0 < 3.0` → **true**

执行原始循环体：
  print a       → global.a = 1.0  → 输出：1

  a = b         → global.a = for-env.b = 1.0

## 关键知识点总结

### 1. for 循环脱糖（Desugaring）

`for` 没有自己的 AST 节点，Parser 在解析阶段将其转换为等价的 `Block + While`：

```
for (init; cond; incr) { body }

等价于：

{
  init;
  while (cond) {
    body;
    incr;
  }
}
```

好处：Interpreter 完全不需要修改，直接复用已有的 `visitWhileStmt` 和 `visitBlockStmt`。

### 2. for 变量的作用域

初始化式中声明的 `var b` 属于 for 脱糖后的外层 `Block`，而不是全局作用域。
循环结束后 `b` 随该 Block 的环境一起销毁，外部无法访问。

```
全局：  a, temp  ← 循环结束后仍可访问
for块：  b       ← 循环结束后消亡
```

### 3. assign 与 define 的区别

| 操作 | 方法 | 行为 |
|------|------|------|
| `var b = 1` | `environment.define()` | 在**当前**环境新建变量 |
| `b = temp + b` | `environment.assign()` | 沿链查找已有变量并更新 |

增量式 `b = temp + b` 使用 `assign`，会沿环境链找到 for-env 中的 `b` 并更新，而不会创建新变量。

### 4. 斐波那契的计算逻辑

`temp` 的作用是在 `a = b` 覆盖 `a` 之前，暂存 `a` 的旧值：

```
迭代  执行前(a, b)   执行后(a, b)   输出
  1   (0, 1)        (1, 1)         0
  2   (1, 1)        (1, 2)         1
  3   (1, 2)        (2, 3)         1
  4   (2, 3)        (3, 5)         2
  5   (3, 5)        —— 条件不满足，退出
```

每次 `b_new = a_old + b_old`，这正是斐波那契递推公式 `F(n) = F(n-1) + F(n-2)`。
